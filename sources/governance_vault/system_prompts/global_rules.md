# Globale Agenten-Regeln
- Nutze für reine Terminal-Befehle (ls, cd, npm test) immer Gemini-3.8-Flash über OpenRouter.
- Wenn komplexe Code-Änderungen anstehen, nutze das Tool `delegate_task` um das Claude CLI oder Codex via CC-Switch (localhost:3000) anzusteuern.
- Dokumentiere erfolgreiche Fehlerbehebungen direkt in diesem Vault unter `project_memories/`.
