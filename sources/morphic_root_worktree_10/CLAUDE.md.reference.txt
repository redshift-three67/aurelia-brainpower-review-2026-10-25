## 🔄 MIGRATIONSABLAUF (Pattern)

1. **Find:** Funktion in main.py Zeilen identifizieren
   ```bash
   grep -n "^def function_name" apps/cli/main.py
   ```

2. **Import:** Abhängigkeiten prüfen
   ```bash
   grep "function_name" apps/cli/main.py -B 50 | grep "^import\|^from"
   ```

3. **Copy:** Funktion nach commands/*.py kopieren
   ```
   - Zielfile auswählen (scan.py, trend.py, etc.)
   - Vollständig mit Helper-Funktionen
   - Alle Constants mitnehmenhm
   ```

4. **Test:** Befehl testen
   ```bash
   python -m apps.cli.main COMMAND --help
   python -m apps.cli.main COMMAND [args...]
   ```

5. **Remove:** Aus main.py löschen
   ```
   - Nur nach erfolgreichem Test!
   - Ggf. Keep-List überprüfen
   ```

6. **Commit:** Mit aussagekräftiger Message
   ```bash
   git add -A
   git commit -m "migrate: FUNCTION_NAME from main.py to COMMAND.py"
   ```
