# 12x12 Resonance Matrix - Kurzanleitung fuer Klienten

Willkommen bei Ihrer individuellen Resonanz-Analyse. Dieses Dokument hilft Ihnen, die Ergebnisse Ihrer Analyse zu verstehen und die Harmonisierung optimal zu nutzen.

## 1. Was ist die 12x12 Resonanz-Matrix?
Das System berechnet die energetische Uebereinstimmung (Resonanz) zwischen Ihrer individuellen Signatur (basierend auf Name, Geburtsdaten und Ort) und einem gewaehlten Fokus-Thema. 
Die 12x12 Matrix ist ein digitales Abbild dieses Resonanzfeldes.

## 2. Die Analyse-Ergebnisse verstehen

### Der Resonanz-Score (0.0 - 1.0)
- **0.0 - 0.3 (Niedrig):** Das Thema ist aktuell wenig im Feld aktiv oder es bestehen Blockaden.
- **0.4 - 0.7 (Mittel):** Eine gute Resonanz, das Thema ist in Bearbeitung.
- **0.8 - 1.0 (Hoch):** Starke energetische Ausrichtung auf das gewaehlte Ziel.

### Die Farbmatrix
Die Farben werden individuell fuer Sie generiert ("Client Coherent"). Sie dienen der visuellen Einschwingung. Betrachten Sie die Matrix waehrend der Harmonisierung fuer eine vertiefte Wirkung.

### HRV-Score (Bio-Feedback)
Falls aktiviert, zeigt dieser Wert Ihre momentane energetische Kohaerenz. Ein hoher Wert (nah bei 1.0) bedeutet, dass Ihr System besonders empfaenglich fuer die Impulse ist.

## 3. Die Harmonisierung (Anwendung)
Nach der Analyse koennen Sie die Harmonisierung starten. Dabei werden die berechneten Frequenzen als Impulse uebertragen.

- **Impuls/Pause:** Standardmaessig 21 Sekunden Impuls gefolgt von 14-21 Sekunden Pause. In der Pause integriert Ihr System die Information.
- **Dauer:** Eine Sitzung dauert meist 21 Minuten (oder ein Vielfaches davon).
- **Audio (Optional):** Falls aktiviert, hoeren Sie eine Solfeggio-Modulation (z.B. 528 Hz), die den Prozess unterstuetzt.

## 4. Empfehlungen fuer die Nutzung
1. **Ruhe:** Suchen Sie sich fuer die Zeit der Harmonisierung einen ruhigen Ort.
2. **Fokus:** Halten Sie Ihr gewaehltes Thema (z.B. "Klarheit" oder "Vitalitaet") leicht im Bewusstsein.
3. **Wasser:** Trinken Sie nach einer Sitzung ausreichend reines Wasser, um den energetischen Prozess physisch zu unterstuetzen.
