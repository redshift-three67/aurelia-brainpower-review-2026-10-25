## 🔧 BEFEHLE (bereits im richtigen Verzeichnis)

```powershell
$env:PYTHONUTF8="1"
& C:\morphic_v1\.venv\Scripts\python.exe -m pytest tests -q

$env:OPENBLAS_NUM_THREADS="1"
& C:\morphic_v1\.venv\Scripts\python.exe -m uvicorn apps.web.main:app --host 127.0.0.1 --port 8000

node --check apps/web/static/app.js
```

**Wichtig:** Immer `C:\morphic_v1\.venv\Scripts\python.exe` explizit verwenden, nicht das bare
`python`/`uvicorn`-Kommando (kann auf ein anderes, numpy-loses venv im PATH zeigen).

**Bekanntes Umgebungsproblem:** Host oft mit nur 3-4 GB freiem RAM → `OpenBLAS error` bei
`import numpy` möglich. Kein Code-Bug; `OPENBLAS_NUM_THREADS=1` setzen, ggf. andere Programme schließen.
