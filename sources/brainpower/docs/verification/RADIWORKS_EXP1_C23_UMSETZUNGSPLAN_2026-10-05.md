New saved immutable basis cannot be injected/edited via case replacement; GV-derived child has no own comparison basis; explicitly choose an eligible Original source or create a fresh Original analysis.
- Snapshot creation requires exact single indexed `.txt` UTF8<=4MiB and byte/rates consistency. Prefix spanning multiple files remains functional Original but visibly unsupported for this experiment. Freeze only selected originalpage1–21; preserve originalindex/sourcevalues separately from score. Matrix scores are different heuristic, not EW/GV/clinicalmeasurements.
- Source seed/mode/runId/copyguard/kernel as provenance. Stochastic output subset already saved is reused unchanged; no new random draws or unequal stochastic rerun. Numerical matrix generation is deterministic context/rate accordingC1.
- Durable store uses unique(scope,requestId) idempotence, immutable input+digest, mutable guarded states, safe errors, per-source stable result session; queued/running recover to interrupted, no automatic replay. Explicit retry clones input, new requestId/job/session with parentJobId; cancel terminal safe. Enforce single live CPU worker/process, cancellation owns only child, join before runtimelease release.
- Dependency location is explicit operator-configured runtime `RADIOWORKS_EXP1_CPU_DEPS`, validate pinned supported imports in subprocess; no inheriting arbitrary PYTHONPATH or fallback. Formula/code fingerprint stored, changed worker invalidates retry. CPU profile80000 only product,64 test-only injected testing not API.
- UI shows Original vs Experimental, named source/catalog/page, weight, explicit start, pending/reconcile/cancel/retry/load historical result, context/formula/provenance. Separate rank/score/intensity columns, no efficacylabels; CopyGuard guards originaldata and results on every publicprojection, textContent only.
