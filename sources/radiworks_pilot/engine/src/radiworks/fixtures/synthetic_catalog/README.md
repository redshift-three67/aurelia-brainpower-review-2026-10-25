# Synthetischer Preview-Katalog

Dieser Katalog enthält ausschließlich erfundene Ratenamen. Er ist für Clean-Checkout,
CI und lokale Vorschauen gedacht und enthält keine Betreiber-, Fall-, Clarke- oder
extern lizenzierten Daten. Er begründet weder eine fachliche Aussage noch eine
Java-Paritätsaussage.
